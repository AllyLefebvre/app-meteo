# Démarrer une tâche

Avant de commencer une tâche, toujours partir d'un `main` à jour :

```bash
git checkout main
git pull
git checkout -b <CLE-numero>-<description-courte>   # ex. WMC-15-entete-desktop
```

Ne jamais créer la branche de travail depuis une autre branche de travail, sauf demande explicite.
